Print this checklist. Then run `python3 "${CLAUDE_PLUGIN_ROOT}/shared/scripts/ddos.py" status` and mark which items the folder shows as done. Do not tick an item you cannot see evidence for.

BEFORE
- [ ] Assumption mapping done and assumptions ranked by risk
- [ ] Interview guide built on the Context -> Buying behavior arc
- [ ] Every question checked for hypothetical language

DURING
- [ ] Asked about the last specific time, not "would you"
- [ ] Talked less than 20% of the time
- [ ] Did not pitch before the interview was over
- [ ] Asked for a referral at the end

AFTER
- [ ] Ran cross-interview pattern analysis once there were 5+ transcripts
- [ ] Red-teamed the patterns before trusting them
- [ ] Scored what was heard on the Evidence Ladder (not everything is evidence)
- [ ] Updated the Evidence Ledger
- [ ] Wrote a decision memo that actually changed a decision
- [ ] Designed the next experiment with a threshold set in advance

The output of customer discovery is not a folder full of notes. It is a better decision.
